# AI Camera Detect 프로젝트

## 1. 프로젝트 개요
**AI Camera Detect**는 웹 브라우저를 기반으로 작동하는 차량용 블랙박스 및 영상 분석 시스템입니다. 별도의 애플리케이션 설치 없이 스마트폰이나 PC의 웹 브라우저를 통해 주행 영상을 녹화하고 서버로 전송합니다. 전송된 영상은 분석을 거쳐 교통위반 등의 이벤트 기록으로 사용자에게 제공됩니다.

## 2. 주요 기능 및 구성 요소

### 2.1. 실시간 웹 블랙박스 녹화 (`blackbox.jsp`)
- **WebRTC & MediaRecorder API**: 디바이스의 카메라 스트림에 접근하여 브라우저 상에서 직접 비디오를 녹화합니다.
- **분할 업로드 및 가변 비트레이트**: 30초 단위로 영상을 분할(Segment)하여 서버에 전송(`uploadSegment`)하며, 네트워크 업로드 지연 시간에 따라 비트레이트(화질)를 유동적으로 자동 조절하여 안정적인 전송을 보장합니다.
- **화면 꺼짐 방지(Wake Lock API)**: 녹화가 진행되는 동안 디스플레이가 절전 모드로 꺼지는 것을 방지합니다.
- **안전한 종료 처리**: 녹화 도중 페이지 이탈 시, 남아있는 영상 조각이 모두 안전하게 서버로 전송되고 병합(`stopRecording`)될 때까지 대기하는 로직이 적용되어 있습니다.

### 2.2. AI 영상 분석
- **외부 Colab 서버 전송**: 업로드가 완료될 시, 외부 Colab와 연결되어 있는 Google Drive 서버로 영상 파일을 업로드합니다.
- **영상 분석 개인정보 보호**: 영상 분석을 의뢰할 시, 사용자의 정보는 전송하지 않고, 영상 제목만 전송하여서 개인정보 보호를 강화합니다.

### 2.3. 블랙박스 보관함 및 이벤트 조회 (`video.jsp`)
- **영상 목록 조회**: 로그인한 사용자의 주행 영상 기록을 최신순으로 조회하며, 현재 서버의 AI 분석 상태(완료/대기)를 확인할 수 있습니다.
- **스트리밍 재생**: `VideoServeServlet` 등을 통해 서버에 저장된 무거운 원본 비디오 파일을 HTML5 비디오 플레이어로 실시간 스트리밍하여 재생합니다.
- **위반 이벤트 탐색**: 분석이 완료된 영상에 한해, 특정 시간대에 감지된 교통위반 이벤트 목록을 리스트 형태로 확인하고 해당 부분의 짧은 이벤트 영상만 따로 재생할 수 있습니다.

## 3. 기술 스택 (Frontend & View)
- **언어 및 템플릿**: HTML5, CSS3, JavaScript (ES6+), JSP
- **주요 Web API**: 
  - `MediaDevices.getUserMedia` (카메라 제어)
  - `MediaRecorder` (영상 녹화)
  - `Screen Wake Lock API` (화면 유지)
  - `Fetch API` & `FormData` (비동기 통신 및 파일 업로드)
